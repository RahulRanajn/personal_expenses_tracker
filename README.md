Personal Expense Tracker

A simple command-line based Personal Expense Tracker built using Python.

Features

- Add Income
- Add Expenses
- View All Transactions
- Calculate Total Income
- Calculate Total Expenses
- Check Remaining Balance
- Store transaction data using JSON
- Load previously saved transactions

Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists & Dictionaries

How to Run

1. Clone this repository:
   
   git clone https://github.com/RahulRanjan/personal_expenses_tracker.git

2. Navigate to the project folder.

3. Run the Python file:
   
   python "Personal Expenses Tracker.py"

Learning Outcomes

This project helped me practice Python fundamentals, functions, loops, conditional statements, lists, dictionaries, JSON, and file handling.
